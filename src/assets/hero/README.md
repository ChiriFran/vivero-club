# Imágenes del hero

Dejá acá las imágenes de la portada. Se detectan automáticamente (no hace falta tocar
el `.env`) y se muestran como un carrusel que rota cada ~5 segundos.

## Formato recomendado

- JPG/WebP/PNG/AVIF, ~1200-1600px de ancho, ideal < 300 KB por imagen.
- Relación vertical o cuadrada funciona mejor (se recortan centradas en el marco).
- Evitá mucho detalle donde caen los badges de las esquinas.

## Varias imágenes

Se ordenan alfabéticamente, por eso conviene nombrarlas `01-hero.jpg`, `02-hero.jpg`,
`03-hero.jpg`, etc. Para cambiar una foto, reemplazá el archivo manteniendo el nombre.

Con una sola imagen se muestra fija, sin rotación.

## Desde el admin

En **Ajustes → Hero · imágenes** podés pegar URLs o subir archivos. Si agregás
imágenes ahí, reemplazan a las de esta carpeta; si borrás todas, se vuelven a usar
estas.
