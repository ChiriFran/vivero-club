# Imágenes de hero

Dejá acá la imagen de fondo de la portada. Se toma automáticamente (no hace falta tocar el
`.env`): se usa la primera imagen por orden alfabético.

## Formato recomendado

- JPG/WebP/PNG/AVIF, ~1920px de ancho, ideal < 300 KB.
- Relación 16:9 o más ancha (se recorta centrada en mobile).
- Poco detalle donde cae el texto: se aplica un velo semitransparente, pero conviene
  que el título y el CTA se lean bien.
- Si la carpeta está vacía, la landing usa el degradado por defecto.

## Varias imágenes

Se usa la primera alfabéticamente. Para priorizar una, nombrala `01-hero.jpg`, `02-hero.jpg`,
etc. Las demás quedan disponibles para cambiar el orden de uso.
